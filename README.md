# LUNA · IA de Mercado

Assistente de inteligência artificial de mercado com análise visual de gráficos, mira de precisão (`X%`, `Y%`), cálculo de tempo de expiração para opções (baseado no timeframe) e síntese de voz em português do Brasil.

## Recursos
- **Leitura de Gráficos e Prints**: Envio de imagens (PNG/JPG) ou colagem direta (`Ctrl+V`).
- **Mira e Posições Exatas**: Mapeamento de suportes, resistências e pontos de entrada na esquerda do gráfico.
- **Tempo de Expiração para Opções**: Sugestão automática de tempo em velas e minutos conforme o timeframe (`M1`, `M5`, `H1`).
- **Interface Holográfica Sci-Fi**: Orbe 3D interativa em Canvas com animações reativas à voz.

## Como Publicar no GitHub Pages
1. Crie um repositório no GitHub (ex: `luna-ia-mercado`).
2. Faça o upload dos arquivos `index.html` e `README.md`.
3. Vá em **Settings > Pages** no seu repositório e ative o GitHub Pages na branch `main` / `root`.
